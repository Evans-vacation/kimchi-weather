# 날씨 (Nalssi) – 안드로이드 날씨 앱 + 홈 화면 위젯 4종

갤럭시 S26+ (안드로이드 16) 기준으로 만든 앱입니다. 날씨 데이터는 Open-Meteo(무료, API 키 필요 없음)를 씁니다.

## 들어 있는 것

| | 크기 | 보여주는 내용 |
|---|---|---|
| 앱 화면 | 전체 화면 | 도시 검색, 현재 날씨, 24시간 예보, 7일 예보, 체감·습도·바람·자외선·미세먼지·일출/일몰 |
| 한 줄 위젯 | 1×4 | 기온, 날씨, 최고/최저, 미세먼지 |
| 소형 위젯 | 2×2 | 지금 기온, 날씨 아이콘, 최고/최저, 체감 |
| 중형 위젯 | 4×2 | 소형 내용 + 앞으로 5시간 예보 |
| 대형 위젯 | 4×4 | 중형 내용 + 미세먼지·초미세먼지 + 5일 예보 |

- 위젯은 앱에서 마지막으로 본 도시의 날씨를 보여줍니다. 앱에서 도시를 바꾸고 나가면 위젯도 바로 바뀝니다.
- 위젯은 약 30분마다 자동으로 새로고침되고, 누르면 앱이 열립니다.
- 배경색은 날씨와 낮/밤에 따라 바뀝니다.
- 앱 오른쪽 위 🔔 에서 **비·눈 시작 알림**(30분마다 확인, 밤 11시~아침 6시 제외)과 **아침 날씨 브리핑**(매일 정한 시간)을 켤 수 있어요.
- 기온 아래에 **어제보다 몇 도 높은지/낮은지** 보여줘요.
- 위젯 배경 그림은 **지역에 맞는 풍경**으로 바뀌어요: 도시, 바닷가, 제주, 한옥(경주·전주·안동), 시골·산, 휴양지, 사막, 알프스, 파리.
- 위젯을 길게 누르고 **설정** 을 누르면 위젯마다 배경 투명도, 글꼴, 글자 크기를 바꿀 수 있어요.

## 처음 한 번만 하는 설정

### 1. GitHub 저장소 만들기
1. github.com에 로그인 → 오른쪽 위 **+ → New repository**.
2. 이름은 `nalssi` 등 아무거나, **Public** 으로 만듭니다.
   (폰 앱이 로그인 없이 새 버전을 찾아야 해서 Public이어야 해요. 서명 키는 아래처럼 비밀 저장소에 넣으니 코드가 공개돼도 다른 사람이 내 앱 업데이트를 만들 수는 없어요.)

### 2. 서명 키 등록 (중요)
업데이트가 설치되려면 모든 버전이 **같은 서명 키**로 만들어져야 해요. 키는 따로 보내 드린 `서명키_보관용.zip` 에 있어요.
1. 저장소 → **Settings → Secrets and variables → Actions → New repository secret**.
2. Name: `KEYSTORE_BASE64`
3. Secret: `KEYSTORE_BASE64.txt` 파일 내용을 전부 복사해 붙여 넣고 **Add secret**.
4. `release.jks` 와 이 txt 파일은 저장소에 올리지 말고 안전한 곳에 보관하세요. 잃어버리면 이후 업데이트를 폰에 설치할 수 없어서 앱을 지우고 새로 설치해야 해요.

### 3. 코드 올리기
1. 저장소 첫 화면에서 **uploading an existing file** → 압축을 푼 `Nalssi` 폴더 **안의 내용 전체**를 끌어다 놓고 **Commit changes**.
   - `.github` 폴더가 함께 올라갔는지 확인하세요. 안 보이면 **Add file → Create new file** 에서 이름에 `.github/workflows/build.yml` 을 입력하고 같은 파일 내용을 붙여 넣어 커밋합니다.
2. **Actions** 탭에서 "Build & Release APK" 가 3~5분 돌아갑니다. 초록 체크가 뜨면 저장소 오른쪽의 **Releases** 에 `날씨 v1.0.1` 이 생깁니다.

### 4. 폰에 처음 설치
1. 폰 브라우저로 저장소의 **Releases** 를 열고 `nalssi.apk` 를 내려받아 누릅니다.
2. "출처를 알 수 없는 앱" → **이 출처 허용** → **설치**. Play 프로텍트 경고가 나오면 **세부정보 → 무시하고 설치**.
   - 예전에 `app-debug.apk` 를 설치했다면 서명이 달라서 덮어쓸 수 없어요. 그 앱을 한 번 지우고 설치하세요.

## 업데이트하는 방법 (이후 매번)

1. GitHub에서 파일을 고쳐 커밋합니다 (웹에서 파일 열기 → 연필 아이콘 → 수정 → **Commit changes**). 커밋 메시지가 업데이트 안내 문구로 폰에 표시돼요.
2. Actions가 자동으로 새 APK를 만들어 Releases에 올립니다 (v1.0.2, v1.0.3 …).
3. 폰에서는:
   - **앱을 열면** "새 버전이 있어요" 창이 뜹니다 → **업데이트**. 처음 한 번은 안드로이드가 "이 출처 허용"과 설치 확인을 물어봐요.
   - 앱이 스스로 한 번 업데이트한 뒤부터는 **위젯이 새로고침될 때(최대 6시간마다) 백그라운드에서 조용히 설치**됩니다. 안드로이드가 허용하는 조건(안드로이드 12 이상, 앱이 직접 설치한 버전)일 때만 가능하고, 안 되는 경우에는 다음에 앱을 열 때 창으로 물어봐요.

## Android Studio로 직접 빌드하기 (선택)

Android Studio에서 **Open** → `Nalssi` 폴더 선택 → ▶ Run. 이렇게 만든 빌드는 디버그 키로 서명되고 자동 업데이트는 꺼져 있어요.

## 위젯 추가하기 (One UI)

홈 화면 빈 곳을 길게 누름 → **위젯** → **날씨** 를 찾아 누름 → 한 줄 / 소형 / 중형 / 대형 중 하나를 골라 **추가**. 추가한 뒤 길게 눌러 크기를 조절할 수 있습니다.

## 파일 구조

```
app/src/main/assets/index.html          앱 화면 (웹 날씨 앱, WebView로 띄움)
app/src/main/java/app/nalssi/
  MainActivity.kt                       앱 화면, 위치 권한, 위젯과 도시 공유
  Weather.kt                            Open-Meteo 호출, 날씨 코드 → 한국어/아이콘
  Widgets.kt                            위젯 3종 그리기와 새로고침
app/src/main/res/layout/widget_*.xml    위젯 레이아웃
app/src/main/res/drawable/ic_w_*.xml    날씨 아이콘 (벡터)
app/src/main/assets/scenes.zip          위젯 풍경 그림 126장 (지역 9 × 날씨 7 × 낮/밤)
.github/workflows/build.yml             커밋하면 APK 빌드 + Release 발행
  Updater.kt (java/app/nalssi)          새 버전 확인과 자동 설치
```
